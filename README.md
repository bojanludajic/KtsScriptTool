# Kotlin Scripting Engine

GUI app made for running .kts scripts built using Kotlin and Compose Desktop.

## Features

- Writing Kotlin scripts and getting their output in real time
- Script error reports
- Script runnig indicator

## Installation

In order to build the app, make sure you have Java 11+ and Gradle (handled automatically if using IntelliJ) installed.

On MacOs/Linux just run:

```
./gradlew run
```
